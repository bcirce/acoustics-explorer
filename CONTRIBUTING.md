# Getting involved

Thanks for wanting to help. The source code of Acoustics Explorer is private, so this
repository has no code to change. There are still good ways to make the map better.

## Suggest an opportunity or a source

Know a course, congress, workshop or job that's missing? Two options:

- **On the site:** use **Submit** on [acousticsexplorer.com](https://acousticsexplorer.com).
  Paste the official link and the form fills itself in. A moderator reviews it before it
  appears.
- **Here:** open a [source or opportunity issue](../../issues/new/choose). This is the right
  place for a whole *source*, like a society calendar or a job board that lists many
  opportunities.

An entry needs an official page from the organiser, and it must be in scope for acoustics.

## Report a bug

Something broken, or an entry that looks wrong? Open a [bug report](../../issues/new/choose).
A screenshot and the page address help a lot. For a wrong entry, say what's wrong and link
the official page if you can.

## Share an idea

Open an [idea issue](../../issues/new/choose). The [roadmap](ROADMAP.md) shows what's already
planned.

## Want to work on the code?

The code isn't open for public contributions right now. If you'd like to collaborate, get in
touch at the address in [SECURITY.md](SECURITY.md) and say a little about yourself.

## Please don't

- Scrape the site or republish its collection as a dataset. Linking to it is very welcome.
- Report security problems in a public issue. See [SECURITY.md](SECURITY.md).
