# Security

If you find a security problem in Acoustics Explorer, please report it **privately**, not in
a public issue.

**Email:** hello@acousticsexplorer.com

Please include what you found, how to reproduce it, and what someone could do with it. You'll
get a reply within a few days. Please give reasonable time for a fix before telling anyone
else.

Thank you for helping keep the site and its visitors safe.
